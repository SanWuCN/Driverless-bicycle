# Web 上位机

本项目提供一个只绑定本机回环地址的 Web 上位机，用于实时查看 STM32/ODrive 同步遥测并在线调整 PID。它不会把数据上传到网络。

## 启动

先关闭其他占用 UART7 或 ODrive USB 的监控脚本。

- macOS：双击项目根目录 `launch_control_station.command`。
- Windows：双击项目根目录 `launch_control_station.bat`。

首次启动需要 Python 3 和网络连接，启动器会在项目内创建 `.venv-control-station`、安装
`requirements-control-station.txt` 中的依赖，之后自动打开本地浏览器。网页顶部串口选择框
列出当前电脑的设备；插拔无线串口后最多等待 5 秒刷新。未选串口时控制按钮不会向车下发指令。

若偏好命令行，可在项目根目录运行：

```bash
python3 -m venv .venv-control-station
.venv-control-station/bin/python -m pip install -r requirements-control-station.txt
.venv-control-station/bin/python tools/control_station.py --open-browser
```

浏览器地址：

```text
http://127.0.0.1:8765
```

如果串口设备名发生变化，可在网页重新选择，或在 macOS 用下面的命令查看：

```bash
ls /dev/cu.*
```

### 打包给其他 Mac

在目标架构的 Mac 上先运行一次启动器，然后在项目根目录运行：

```bash
./tools/build_control_station_mac.sh
ditto -c -k --sequesterRsrc --keepParent dist/BikeControlStation.app dist/BikeControlStation-mac.zip
```

分享 `dist/BikeControlStation-mac.zip`。收件人解压后打开 `BikeControlStation.app`，
应用会自动打开浏览器，无需安装 Python 或另行复制网页文件。构建产物不提交 Git。
Intel 与 Apple Silicon 需分别在对应架构构建；当前为未签名/未公证的本地构建，
经互联网下载后 macOS 可能要求用户在系统设置中手动批准，不能保证首次双击直接运行。
正式面向他人分发若要无警告启动，需要 Apple Developer ID 签名与公证。
数据与控制只在 `127.0.0.1:8765` 提供，不向外网发布；应用日志存于
`~/Documents/BikeControlStation/logs/`。

### Windows 免安装版

仓库的 GitHub Actions 会在真正的 Windows x64 环境运行
`tools/build_control_station_windows.ps1`，生成构建产物
`BikeControlStation-Windows-x64.zip`。在仓库的 **Actions → firmware-build →
Artifacts** 下载后解压，双击目录内的 `BikeControlStation.exe` 即可；无需另外安装
Python。首次连接 USB-UART 或 ODrive 时仍需安装对应的 Windows USB 驱动。

如果控制站已经在后台运行，再次双击应用会直接打开现有的
`http://127.0.0.1:8765`，不会再因为端口占用而静默退出。若该端口被其他软件占用，
应用会拒绝复用，避免误打开无关服务。

## 功能

- 同步显示横滚角、控制误差、动态零点、角速度、目标角速度、轮速、速度指令、原始/限幅加速度、角速度环 P/I/D 分项、ODrive 电流和母线数据。
- 显示安全状态机、限幅、超时、ODrive 故障和动态零点门控标志。
- 在线调整角速度环、角度环、轮速回正环和转向环 PID；范围与 STM32 固件的白名单完全一致。
- 正式转向控制：左/右 `10°`、`15°` 和一键回中预设，滑块范围为 `±15°`、步进
  `0.5°`、非零死区为 `±5°`。拖动滑块即更新目标，不需要点击执行；网页使用 140 ms
  防抖并只保留最新目标，避免无线链路堆积沿途命令。界面角度按当前标定
  `1° = 10 µs` 换算，代表控制指令角；STM32 底层仍使用已验证的 PWM 偏移协议并负责
  限速、加减速和回中消隙。实测前轮机械角后，只需更新这一标定系数。
- 后轮可选择前进、后退、停止并用滑块设置 `0.01…0.10 m/s`，默认 `0.03 m/s`。
  STM32 使用限加加速度的 S 曲线平滑启停，加速/减速/加加速度上限分别为
  `0.025 m/s²`、`0.05 m/s²`、`0.10 m/s³`，并保留 3 秒命令超时和安全门控。
- 一键循环演示：前进 2 m并停稳，右转 15°等待5秒，回中，左转15°等待5秒，
  前进1 m、后退1 m、回中、再后退2 m，随后重复。
- 演示里程使用后轮编码器与IMU纵向加速度融合；检测到起步/换向打滑时降低编码器权重，
  避免把空转全部计入位移。演示要求IMU加速度新鲜，否则拒绝启动或立即停止。
- 默认只接收 2 Hz 基础状态，不传输 IMU 数据；“开启详细遥测”后才请求20 Hz平衡/IMU
  曲线。开始记录会自动开启详细遥测，停止记录后自动回到基础模式。
- 每条修改都使用现有 CRC16 协议；回执丢失时会尝试用新鲜状态帧确认目标是否已执行。
- 支持扰动时刻标记、暂停曲线、10/30/60/120 秒窗口、最近窗口 CSV 导出。
- 支持把完整调参过程记录到 `logs/web_pid_tuning_*.csv`。
- “开始记录 → 施加一次扰动 → 完全松手 → 稳定后停止记录”会冻结并显示该段曲线，自动计算横滚最大峰值、反向过冲、±0.3°/±0.2°恢复时间、角速度/轮速/电流峰值、加速度限幅占比与安全状态。网页只显示指标和质量等级，不展示自动生成的解释性文字；完整评估细节保存在 JSON。
- 每次停止记录还会生成同名 `*.analysis.json`，保存机器可读的评估结果，便于以后批量比较多组 PID。

## 扰动测试操作

1. 扶稳车辆，点击“开始记录”，先保持约 1.5 秒，让上位机取得本次基线噪声。
2. 只施加一次方向明确的推力，然后完全松手；不要在恢复过程中持续扶车修正。
3. 等车辆重新稳定至少 1 秒，再点击“停止记录”。
4. 页面自动切换到“已记录区间 · 冻结视图”。检查最大峰值、反向过冲、恢复时间、限幅占比和触发状态；点击“返回实时”继续观察。

恢复时间的判据是：从主峰开始，横滚误差持续 1 秒位于目标带内，同时横滚角速度绝对值不超过 0.8°/s。综合评分适合在相近推力、相近电量和相同机械状态下横向比较，不应单独代替现场安全判断。

## 安全规则

1. 网页修改的是 MCU RAM，立即生效，但 STM32 复位后恢复编译默认值。
2. 每次只调整一个控制环，每次只做小步变化。
3. 扰动试验时必须有人在车旁，接近 6° 或连续两次摆幅增大时立即扶住，不等待 8°保护。
4. 不要同时运行 `balance_telemetry.py`、`steering_console.py` 或其他串口监控程序；同一串口只能由一个进程占用。
5. 只有在多组静态、扰动和长时间试验都通过后，才把参数写回固件并烧录。
6. 上位机每 800 ms 发送无回执的轻量保活；串口或上位机进程中断后，STM32 在3秒内
   撤销后轮输出并让舵机平滑回中。初次验证前必须固定车架、悬空后轮，以 `0.03 m/s`
   确认前进/后退方向、`0.077 m/turn`系数以及IMU X轴正负号；方向未确认前不要在地面
   启动演示。
7. IMU/编码器互补融合可以抑制部分打滑误差，但单靠这两种传感器无法保证识别恒定打滑；
   演示中的 2 m/1 m 位移仍是估计值。未经过现场方向、轮径、加速度零偏及实测距离校准，
   不得把它当作精确定位或无人值守导航。
8. 关闭网页并不会立即停止后轮；必须先按“停止”并确认反馈。断开串口后 3 秒命令超时
   是兜底机制，不可替代人在车旁的急停。失去平衡许可/后轮反馈时固件立即置零输出。

## 无线 UART7

无线模块接入后在页面顶部选择电脑端串口；也可以在命令行显式指定：

```bash
./.venv-control-station/bin/python tools/control_station.py \
  --port /dev/cu.usbserial-140
```

固件默认只输出每500 ms一条46字节、带CRC的基础状态帧，持续负载约92 byte/s；其中
没有横滚角、角速度或航向等IMU数据。点击“开启详细遥测”后才增加65字节/20 Hz平衡帧
和34字节/约3.3 Hz转向帧。PID参数通过连接时的`GET`回执取得，不依赖遥测帧重复发送。

## 可选参数

```bash
python tools/control_station.py --help
```

- `--http-port`：网页端口，默认 `8765`。
- `--history-seconds`：服务器内存中保留的历史长度，默认 600 秒。
- `--odrive-rate`：ODrive USB 轮询频率，默认 20 Hz。
- `--host`：默认 `127.0.0.1`，不建议改为局域网地址。
- `--port`：可选；省略时在网页选择。
- `--open-browser`：启动后自动打开网页。
